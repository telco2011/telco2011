I build product backends and the tooling around them — mostly TypeScript on
NestJS and React/Next.js over PostgreSQL, with a growing pile of MCP servers and
agent tooling. Most of my open source lives under
[**The Dave Stack**](https://github.com/The-Dave-Stack).

### What I'm working on

- [**herdr-keymap**](https://github.com/The-Dave-Stack/herdr-keymap) — a herdr
  plugin that shows every keybinding in an overlay palette and runs the ones
  with a CLI equivalent.
- [**mcp-backlog-md**](https://github.com/The-Dave-Stack/mcp-backlog-md) — MCP
  server for driving Backlog.md task boards.
- [**product-catalog-mcp**](https://github.com/The-Dave-Stack/product-catalog-mcp)
  — an MCP server built around Resources and Prompts, not just function calling.
- [**product-catalog**](https://github.com/The-Dave-Stack/product-catalog) — a
  Spring Boot REST API for catalog management.
- [**inet-vpn-plasmoid**](https://github.com/telco2011/inet-vpn-plasmoid) — KDE
  Plasma panel widget for VPN and network status.
